# 🚧 Anime Showcase

This is an under-development web application built using **Next.js**, **Tailwind CSS**, and **Framer Motion**. It aims to deliver a smooth, responsive, and interactive user experience.

---

## 🔧 Tech Stack

- **Next.js** – Framework for server-rendered React applications.
- **Tailwind CSS** – Utility-first CSS framework for rapid UI development.
- **Framer Motion** – Powerful animation library for React.

---

## 📦 Installation

```bash
# Clone the repository
git clone git@github.com:fareedzafar657/anime-showcase.git

# Navigate into the project directory
cd anime-showcase

# Install dependencies
npm install
